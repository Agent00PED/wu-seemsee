# WU SeemSee Client

Next.js frontend for WU SeemSee.

## Getting Started

```bash
npm install
npm run dev   # http://localhost:3000
```

Requires server running at `http://localhost:4000` (see [../server/README.md](../server/README.md)).

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start dev server |
| `npm run build` | Build for production |
| `npm run start` | Start production server |
| `npm run lint` | Run lint |
